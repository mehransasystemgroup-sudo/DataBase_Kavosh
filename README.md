# کاوشگر پایگاه داده (DataBase Kavosh)

اپلیکیشن مستقل کاوش ساختار پایگاه دادهٔ نرم‌افزار سازمانی — جست‌وجو در **۳٬۴۲۸ جدول** و
**۴۰٬۷۸۷ ستون**، مشاهدهٔ روابط، کلیدها، ایندکس‌ها و مقادیر کددار، گراف بصری روابط،
مسیریابی JOIN و تولید کوئری T-SQL.

این اپ فقط بخش «کاوش پایگاه داده» از ابزار گزارش‌ساز است؛ ساخت گزارش، RDL، چت هوشمند و
سایر بخش‌ها حذف شده‌اند تا هستهٔ کاوش سبک، سریع و بدون کد اضافه بماند.

---

## امکانات

| بخش | توضیح |
| --- | --- |
| **جست‌وجوی هوشمند** | جست‌وجوی تمام‌متن روی نام انگلیسی، عنوان و توضیح فارسی و نام ستون‌ها، با ریشه‌یابی سبک فارسی و نرمال‌سازی حروف عربی/فارسی |
| **فیلترهای پیشرفته** | وضعیت داده (دارای داده / خالی)، نوع دادهٔ ستون، بازهٔ تعداد ردیف، اسکیما و ترتیب نتایج |
| **جزئیات جدول** | ستون‌ها با نشان کلید اصلی/خارجی/ایندکس، روابط ورودی و خروجی، ایندکس‌های واقعی، مقادیر کددار (Enum) و هشدارهای دانشی |
| **گراف روابط جدول** | چهار نما: نیرو‌محور، سلسله‌مراتبی، شعاعی و ERD متنی (Mermaid) |
| **گراف روابط اسکیما** | گراف کل یک اسکیما با فیلتر درجهٔ اتصال، سقف گره، اسکیماهای بیرونی و پنل بازرسی گره |
| **مسیریاب JOIN** | کوتاه‌ترین زنجیرهٔ اتصال بین دو جدول، همراه با هشدار مسیرهای بلند و تأییدنشده |
| **تولید T-SQL** | کوئری‌های بازیابی، پیوند با والدها و تجمیع، بر پایهٔ ستون‌های انتخابی و با فیلتر سال مالی |
| **آموزش دانش** | ثبت عنوان/توضیح جدول، معنی مقادیر کددار و تأیید مسیر JOIN — با اولویت بر استنتاج خودکار |
| **تم روشن و تیره** | تم پیش‌فرض مشکی/سبز و تم روشن سفید/سبز، با یک منبع حقیقت رنگ برای کل اپ و گراف‌ها |

طراحی کاملاً واکنش‌گراست: از گوشی تا نمایشگر عریض، هر بخش چیدمان متناسب خودش را دارد.

## معماری

```
run.ps1                راه‌انداز ویندوز: نصب، بیلد، ایندکس و اجرا با یک دستور
Start-Kavosh.cmd       پوستهٔ دوبارکلیک برای run.ps1

backend/
  app/main.py          سرور FastAPI — پوسته‌ای نازک روی core/
  core/search.py       موتور کاوش: جست‌وجو، جزئیات، گراف، مسیریابی JOIN
  core/writer.py       ثبت دانش کاربر در kb/
  core/textnorm.py     نرمال‌سازی و ریشه‌یابی متن فارسی
  scripts/build_index.py   ساخت ایندکس SQLite از kb/
  kb/                  منبع حقیقت دانش (YAML): ساختار، معنا، روابط، enum، ایندکس
  instances/live/      آمار ردیف‌های نصب فعلی
  index/               ایندکس مشتق‌شده (در git نیست — خودکار ساخته می‌شود)

frontend/
  src/App.jsx                    پوستهٔ اپ و سوییچ نما
  src/views/ExplorerView.jsx     جست‌وجو، فیلترها و فهرست نتایج
  src/views/TableDetail.jsx      جزئیات جدول با تب‌های روابط/ستون/نمودار/SQL/ایندکس/کدینگ
  src/views/SchemaGraphView.jsx  گراف کل اسکیما
  src/views/TeachDialog.jsx      ثبت دانش
  src/components/graph/          زیرساخت D3 (زوم، اندازه‌گیری، پالت تم)
  src/lib/schemaTheme.js         پالت رنگ اسکیماها برای هر دو تم
  src/index.css                  توکن‌های رنگ — تنها منبع حقیقت تم
```

**ایندکس یک مصنوع مشتق است.** منبع حقیقت `backend/kb/*.yaml` است؛ ایندکس همیشه با یک
دستور از آن بازساخته می‌شود و هرگز نباید دستی ویرایش یا در git ذخیره شود.

## اجرا روی ویندوز (ساده‌ترین راه)

فایل **`Start-Kavosh.cmd`** را دوبار کلیک کنید. همین.

اسکریپت خودش محیط پایتون را می‌سازد، وابستگی‌ها را نصب می‌کند، رابط کاربری را بیلد
می‌گیرد، ایندکس جست‌وجو را از `kb/` می‌سازد و مرورگر را روی برنامه باز می‌کند. بار اول
چند دقیقه طول می‌کشد؛ دفعات بعد چند ثانیه، چون هر گام فقط در صورت نیاز اجرا می‌شود.

اگر ترجیح می‌دهید مستقیم از PowerShell اجرا کنید:

```powershell
.\run.ps1                      # اجرا روی http://127.0.0.1:8321
.\run.ps1 -Port 9000           # پورت دلخواه
.\run.ps1 -Rebuild             # ساخت دوبارهٔ ایندکس و بیلد
.\run.ps1 -Dev                 # حالت توسعه با بازتاب زندهٔ تغییرات کد
.\run.ps1 -NoBrowser           # بدون باز کردن خودکار مرورگر
```

اگر ویندوز اجرای اسکریپت را مسدود کرد (خط‌مشی اجرا)، یا `Start-Kavosh.cmd` را دوبار
کلیک کنید یا:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

**پیش‌نیازها:** [پایتون ۳٫۱۰ یا بالاتر](https://www.python.org/downloads/) — هنگام نصب
گزینهٔ «Add python.exe to PATH» را تیک بزنید — و [Node.js LTS](https://nodejs.org).
Node.js فقط برای ساخت رابط کاربری لازم است؛ اگر بیلد از قبل موجود باشد اسکریپت سراغش
نمی‌رود.

## اجرا روی لینوکس و مک

### بک‌اند

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 -m app.main            # http://127.0.0.1:8321
```

در اولین اجرا، اگر ایندکس وجود نداشته باشد خودش از `kb/` ساخته می‌شود (چند ثانیه).
برای ساخت دستی:

```bash
python3 scripts/build_index.py --kb kb --out index/kb.sqlite --instance instances/live
```

### فرانت‌اند

```bash
cd frontend
npm install
npm run dev                    # http://127.0.0.1:3000
```

سرور توسعه مسیر `/api` را به بک‌اند پروکسی می‌کند. برای بک‌اند روی آدرس دیگر:

```bash
BACKEND_URL=http://192.168.1.10:8321 npm run dev
```

### اجرای یکپارچه (تولید)

```bash
cd frontend && npm run build
cp -r dist ../backend/static
cd ../backend && python3 -m app.main
```

بک‌اند در صورت وجود پوشهٔ `static/`، خود اپ را هم سرو می‌کند و همه‌چیز روی یک پورت
(۸۳۲۱) بالا می‌آید.

متغیرهای محیطی بک‌اند: `KB_ROOT`، `KB_INDEX`، `KB_INSTANCE`، `STATIC_DIR`، `HOST`، `PORT`.

## API

| مسیر | کار |
| --- | --- |
| `GET /api/health` | آمار پایگاه دانش |
| `GET /api/search` | جست‌وجو با فیلتر: `q, schema, dataStatus, fieldType, minRows, maxRows, sortBy, sortOrder, limit` |
| `GET /api/columns` | جست‌وجوی ستون بر اساس نام |
| `GET /api/schemas` | فهرست اسکیماها با تعداد جدول و ستون |
| `GET /api/schema/{schema}/graph` | گراف روابط اسکیما: `includeExternal, onlyWithData, maxNodes` |
| `GET /api/table/{full_name}` | جزئیات کامل جدول |
| `GET /api/joinpath` | مسیر JOIN: `source, target, maxHops, verifiedOnly` |
| `GET /api/neighbours/{full_name}` | جدول‌های مجاور در گراف |
| `POST /api/knowledge` | ثبت دانش: `{kind: table\|enum\|join, payload}` |
| `POST /api/index/rebuild` | بازسازی ایندکس از `kb/` |

مستندات تعاملی: `http://127.0.0.1:8321/api/docs`

## تم

رنگ‌ها فقط در `frontend/src/index.css` تعریف شده‌اند و `tailwind.config.js` آن‌ها را به
کلاس‌های ابزاری وصل می‌کند. گراف‌های D3 هم همان متغیرها را از ریشهٔ سند می‌خوانند
(`useGraphTheme`). بنابراین تغییر یک رنگ در تم، همه‌جا — از دکمه تا خط یال گراف — اعمال
می‌شود و هیچ رنگ سخت‌کدشده‌ای برای تعویض تم جا نمی‌ماند.

- **تیره (پیش‌فرض):** مشکی با ته‌رنگ سبز `#050806` + سبز `#22C55E`
- **روشن:** سفید مایل به سبز `#F4F8F5` + سبز `#15803D`

همهٔ جفت‌های متن/پس‌زمینه در هر دو تم دست‌کم ۴٫۵:۱ کنتراست دارند (سنجیده‌شده، نه تخمینی).

میان‌برها: `/` برای پریدن به جست‌وجو، `↑`/`↓` برای پیمایش نتایج، `Enter` برای باز کردن.

هر نما نشانی خودش را دارد (`#/table/FIN3.Voucher`، `#/graph/ACC`، `#/q/سند`)، پس لینک هر
جدول قابل اشتراک‌گذاری است و دکمهٔ «بازگشت» مرورگر همان‌طور کار می‌کند که انتظار می‌رود.

انتخاب کاربر در `localStorage` می‌ماند و پیش از اولین رنگ‌آمیزی صفحه اعمال می‌شود تا
هنگام بارگذاری، صفحه سفیدی یا سیاهی ناگهانی نزند.
